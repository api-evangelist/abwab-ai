# Abwab.ai

> AI-powered credit intelligence platform for MSME (micro, small, and medium enterprise) lending. Banks, NBFIs, fintechs, funds, and platforms use Abwab to originate loans, assess credit risk, price, and monitor MSME loan portfolios across the full lending lifecycle. API-first, versioned REST API with webhook notifications; focused on the Saudi Arabian market with in-Kingdom data residency and SAMA/PDPL/Sharia alignment. Backed by Speedinvest.

## APIs

- [Credit Intelligence API](https://abwab.ai/platform/api): Versioned REST API for MSME credit assessment and decisioning (e.g. POST /v1/assessments returns score, decision, risk_flags, price). Base URL https://api.abwab.ai.
